Managed TikTok Account Visibility

Connect a TikTok account and display authorized profile information and recent posts in a website dashboard.

Genie Market is a web application for managed TikTok creator and business accounts. Users connect through TikTok Login, authorize access, and Genie Market displays profile and recent post data in a dashboard for visibility, analytics, and reporting workflows.

Open Dashboard Privacy Policy Terms of Service

Authorized Access

Users connect TikTok accounts through TikTok Login and grant access only to the scopes required for profile and recent post display.

Profile Display

Genie Market displays connected TikTok account profile information inside the website dashboard after authorization.

Recent Post Display

Genie Market displays recent posts from the connected TikTok account in the dashboard for managed account workflows.

How Genie Market Works

1. Connect Account

User starts TikTok Login from the website.

2. Authorize Access

User authorizes the requested TikTok scopes.

3. Retrieve Data

Genie Market receives authorized profile and recent post data.

4. Show Dashboard

The website displays the connected account and recent posts.

Scopes Used
• user.info.basic — connected TikTok account profile display
• video.list — recent TikTok post display in the dashboard
